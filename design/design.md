# Design assets

Store future Eleftheria design assets in this directory using purpose-based folders:

- `brand/`
- `logo/`
- `palette/`
- `posters/`
- `website-wireframes/`
- `prototypes/`
- `screenshots/`

Use lowercase, hyphen-separated names that identify the asset, version or date when useful, and file purpose. For example: `eleftheria-wordmark-v01.svg`, `home-wireframe-2026-09-30.png`, or `gallery-mobile-prototype-v01.fig`.

Avoid ambiguous names such as `final`, `new`, or `latest`. Keep editable source files alongside exports when practical.
