# Future testing requirements

Testing should be introduced alongside website development and revisited as content and language support grow.

## Functionality

Verify navigation, language selection, links, forms, and content paths behave as intended.

## Responsive behaviour

Test phone, tablet, and desktop layouts, including menus, language controls, reading widths, and gallery presentation.

## Accessibility

Test keyboard navigation, visible focus, contrast, semantic structure, readable text, and assistive-technology access.

## Performance

Review loading behaviour for fonts, images, galleries, and translated content, especially on slower connections.

## Content quality

Check attribution, category placement, editorial context, sources and data for research, and clarity around translation or adaptation.

## Multilingual behaviour

Test each supported UI locale, script rendering, text expansion, language persistence, missing translations, and right-to-left behaviour where relevant.
