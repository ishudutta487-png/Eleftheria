# Project overview

## Project identity

Eleftheria is a youth-led platform with the identity **culture · communication · concern**.

## Core idea

The platform is intended to give young people a real place to think about the world, express ideas, share creative work, research global issues, and communicate across language barriers.

## Problems being addressed

- Xenophobia.
- Glossophobia.
- Barriers that prevent ideas from being heard because of language fluency.

## Current website scope

The current site structure includes Home, Gallery, About, The Team, Contact, and a language-selection panel. The project is in early development.

The following are planned ideas, not current capabilities: Community Engagement, Global Conferences, Model UN, and Community, Elsewhere.
