# Design system

## Brand

- **Name:** Eleftheria
- **Core identity:** culture · communication · concern
- **Wordmark font:** Middleburg Regular

## Colour palette

| Colour | Hex | Intended role |
| --- | --- | --- |
| Light Blue | `#9ED3EE` | Open, light surfaces and accents |
| Warm Cream | `#EDC99D` | Warm background or supporting surface |
| Muted Grey | `#9AA7AD` | Secondary neutral elements |
| Warm Taupe | `#988B7B` | Earthy supporting accent |
| Deep Blue-Grey | `#46606E` | Primary text, contrast, and grounding elements |

Treat the palette as a design system: use colours intentionally for their roles rather than distributing all five equally.

## Typography rules

- Use Middleburg Regular for the Eleftheria wordmark only.
- Choose supporting type that remains legible across the writing systems used by the project.
- Maintain clear hierarchy for editorial reading: headings, bylines, body copy, captions, and metadata.
- Do not substitute a typeface that cannot reliably render required scripts.

## Multilingual visual identity

Multiple writing systems are a core part of Eleftheria’s identity, not decoration. One current expression is: **संस्कृति · تواصل · Quan tâm**. Layout and typography should give each script equal care and legibility.

## Design direction

The website should feel human, cultural, editorial, youth-oriented, thoughtful, open, and distinctive. Avoid generic corporate, NGO, and startup conventions.

## Accessibility considerations

- Preserve sufficient text and interface contrast.
- Do not rely on colour alone to communicate meaning.
- Support readable type sizes, clear focus states, keyboard use, and responsive reflow.
- Test script rendering, text expansion, and directionality for supported locales.
