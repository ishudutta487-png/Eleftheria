# Website architecture

## Navigation

The current navigation is Home, Gallery, About, The Team, and Contact. A language-selection panel is a core website feature.

## Page purposes

| Page | Purpose |
| --- | --- |
| Home | Introduce Eleftheria and its purpose. |
| Gallery | Present creative and contributor work. |
| About | Explain the project’s identity and mission. |
| The Team | Identify the people behind the project. |
| Contact | Provide a route for contact. |

## Language selector

The selector lets visitors choose a comfortable or native interface language. It should be easy to find, retain the visitor’s choice where appropriate, and remain usable on small screens.

## Interface language and content language

Interface language controls navigation, labels, controls, and system messages. Content language describes the language of a specific essay, poem, artwork description, or research piece. They may differ.

## Future content model

Future content should be structured around Voice, Talents, Research, and Language Access, with fields for title, contributor, publication information, content language, available translations, attribution, and source/context where relevant.

## Responsive requirements

Navigation, language selection, reading layouts, galleries, and interactive controls must work across phone, tablet, and desktop sizes without loss of access or meaning.
